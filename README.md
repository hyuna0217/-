# UniPath MVP Prototype

A lightweight web prototype for a U.S. undergraduate admissions planning app focused on top schools.

## Features

- Select up to 30 target schools (preloaded)
- Auto-generate a backwards plan from a target submission deadline
- Produce weekly tasks for testing, essays, recommendations, and documentation
- Save and reload plan state in browser local storage

## Run locally

Open `index.html` in a browser.

## Files

- `index.html` - app structure
- `styles.css` - UI styling
- `app.js` - school data + roadmap generation logic
